# yzu

元智大學電機系課程練習。

## 程式設計（大一上）

作業依課程 Exercise 編號分資料夾。

| 資料夾 | 主題 | 題數 |
|---|---|---|
| `Exercise_01` | 輸入、運算子、格式化 | 4 |
| `Exercise_02` | 條件判斷、math 模組 | 3 |
| `Exercise_03` | while 迴圈 | 4 |
| `Exercise_04` | for 迴圈、驗證輸入 | 5 |
| `Exercise_05` | 字串處理 | 3 |
| `Exercise_06` | 字串驗證（IP / Email） | 3 |
| `Exercise_07` | 自訂函式 | 4 |
| `Exercise_08` | **檔案讀寫** | 3 |
| `Exercise_09` | **檔案 + 例外處理** | 4 |
| `Exercise_10` | list 函式 | 4 |
| `Exercise_11` | 綜合演算法 | 6 |
| `Exercise_12` | **dict + 檔案** | 2 |
| `Exercise_13` | **CSV 分組統計** | 4 |

粗體是檔案處理，佔了後半整條主軸，第三次小考也考這個。

## 建議順序

不要照 01 到 13 做。01–07 對有 C 基礎的人是複習，先攻 08 開始的檔案處理。
