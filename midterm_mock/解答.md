## Part A

| # | 運算式 | 答案 | 說明 |
|---|---|---|---|
| A1 | `s[2:7]` | `'llo W'` | 半開區間，含 2 不含 7 |
| A2 | `s[::-1]` | `'dlroW olleH'` | 整串反轉 |
| A3 | `s[::-3]` | `'dooe'` | 從尾端每 3 個取一個 |
| A4 | `d[1::3]` | `'147'` | 從 index 1 起每 3 個 |
| A5 | `d[-3:-7:-1]` | `'7654'` | 倒著走，含 -3(=7) 不含 -7(=3) |
| A6 | `d[7:2]` | `''` | step 是正的卻 start>finish → 空字串，**不報錯** |
| A7 | `len('a\tb\\n')` | `5` | 拆開是 `'a'`、TAB、`'b'`、`'\'`、`'n'`。`\t` 是**一個** tab 字元；`\\` 是**一個**反斜線；後面的 `n` 是普通字母 n（不是換行！）|
| A8 | `-2 ** 2` | `-4` | `**` 優先於一元負號，等於 `-(2**2)` |
| A9 | `2 ** 3 ** 2` | `512` | `**` 右結合，等於 `2**(3**2)` = 2**9 |
| A10 | `-7 // 2` | `-4` | 向下取整（往負無窮），不是往 0 截斷 |

> A7 的逃脫字元最容易數錯，建議自己打一次 `print([c for c in 'a\tb\\n'])` 看拆出來是哪五個字元。

## Part B

- **B1** `2.0`，型態是 **float**。Python 3 的 `/` 永遠回傳 float，就算整除也一樣。要整數結果用 `//`。
- **B2** `False`。0.1 和 0.2 在二進位浮點數裡都無法精確表示，相加後是 `0.30000000000000004`。浮點數不應該用 `==` 比較，要判斷「差距夠小」。
- **B3** `32`。大小寫字母的 UTF-8 編碼差 32（`'A'`=65, `'a'`=97）。
- **B4** `2` 和 `12` 都不是 0，會被當成 `True`，整個條件永遠成立。`or` 的左右兩邊都必須是完整的判斷式：
  ```python
  if m == 1 or m == 2 or m == 12:
  ```
- **B5** 它們是 Python 內建 function。拿來當變數名會把原本的 function 蓋掉，之後在同一個程式裡就不能再呼叫 `max(...)`，而且錯誤訊息很難懂。

## Part C

**C1 — 輸入 0 會印出 `-`**
`if x <= 0` 把 0 也當成負數，印了負號後 `while i <= 0` 一次都沒跑，結果只剩一個 `-`。
另外題目要求間隔四個空格，這份是對的（`end="    "`）。

```python
if x == 0:
    print(0)
else:
    if x < 0:          # 改成 < 0
        print("-", end="")
        x = -x
    ...
```

**C2 — 一開始就輸入 -1 會 ZeroDivisionError**
`count` still 0，第 12 行除以零崩潰。

```python
if count == 0:
    print("no grade")
else:
    print(total / count)
```

**C3 — 範圍小於 2 時會誤印**
`while True` 把 break 放在迴圈**結尾**，變成 do-while，所以 `num = 2` 一定會先跑一次。輸入 1 或 0 都會印出 2 的判斷結果。

```python
num = 2
while num <= num_range:    # 條件放前面
    ...
    num += 1               # 刪掉結尾的 if/break
```

## Part D 參考解答

**D1**
```python
price = int(input("Input Price: "))
change = 1000 - price
n500 = change // 500; change %= 500
n100 = change // 100; change %= 100
n50  = change // 50;  change %= 50
n10  = change // 10;  change %= 10
n5   = change // 5;   change %= 5
n1   = change
print(f"500: {n500}")
print(f"100: {n100}")
print(f"50: {n50}")
print(f"10: {n10}")
print(f"5: {n5}")
print(f"1: {n1}")
```

**D2**
```python
while True:
    n = int(input("input n "))
    if n == 0:
        break
    elif n < 0:
        print("invalid")
    else:
        total = 0
        m = n                  # 另存一份，才不會把 n 改掉
        while m > 0:
            total += m % 10
            m //= 10
        print(f"{n} -> {total}")
```
陷阱：直接拿 `n` 去除會把原值破壞掉，最後印不出 `1234 -> 10` 的左半邊。

**D3**
```python
s = input("input s ")
print(s[::2])
print(s[::-1])
if s == s[::-1]:
    print("palindrome")
else:
    print("not palindrome")
```
回文判斷用 `s == s[::-1]` 一行解決，不需要迴圈兩頭比對。

**D4**
```python
s = input("input s ")
k = int(input("input k "))
if k <= 0:
    print("invalid")
else:
    out = ""
    i = 0
    while i < len(s):
        if i > 0:
            out += "-"
        out += s[i:i+k]
        i += k
    print(out)
```
陷阱：
- `s[i:i+k]` 超出長度**不會報錯**，自動截到結尾 —— 所以最後一組不用特別處理。
- 分隔符號要在「不是第一組」時才加，否則開頭會多一個 `-`。
- `out` 要累加（`+=`），不是覆寫。
