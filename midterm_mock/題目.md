## Part C 找錯（每題 8 分，共 24 分）

指出 bug、說明哪一種輸入會觸發、並寫出最小修正。

**C1**
```python
x = int(input("enter "))
if x <= 0:
    print("-", end="")
    x = -x
i = 1
while i <= x:
    i *= 10
i //= 10
while i >= 1:
    print(x // i, end="    ")
    x -= i * (x // i)
    i //= 10
```

**C2**
```python
total = 0
count = 0
while True:
    g = int(input("enter grade "))
    if g == -1:
        break
    elif g < 0 or g > 100:
        print("invalid")
    else:
        total += g
        count += 1
print(total / count)
```

**C3**
```python
num_range = int(input("enter range "))
num = 2
while True:
    divisor = 1
    s = 0
    while num > divisor:
        if num % divisor == 0:
            s += divisor
        divisor += 1
    if s == num:
        print(num, "is perfect")
    num += 1
    if num > num_range:
        break
```

## Part D 程式撰寫（每題 ?? 分，共 26 分）

**D1（Ch1，6 分）找零錢**
輸入商品價格（0 < price < 1000），拿 1000 元鈔付款，輸出最少的零錢數量。
面額：500、100、50、10、5、1。**不可使用迴圈**，只用整數除法與餘數。

```
Input Price: 237
500: 1
100: 2
50: 1
10: 1
5: 0
1: 3
```

**D2（Ch2，6 分）各位數字之和**
使用 while-loop 持續輸入整數 n：
- n == 0 → 結束程式
- n < 0 → 印 `invalid`，繼續要求輸入
- 否則輸出 n 的每一位數字相加的結果

```
input n 1234
1234 -> 10
input n 305
305 -> 8
input n -5
invalid
input n 0
```

**D3（Ch3 / 4.1，6 分）切片練習**
輸入一個字串 s，依序輸出三行：
1. s 中索引為偶數的字元（0, 2, 4, …）
2. s 反轉後的字串
3. 若 s 是回文印 `palindrome`，否則印 `not palindrome`

三題都必須用**切片**完成，不可用迴圈。

```
input s abcdef        input s abcba
ace                   aca
fedcba                abcba
not palindrome        palindrome
```

**D4（Ch3 / 4.2，8 分）分組**
輸入字串 s 和正整數 k，將 s 每 k 個字元分成一組，組與組之間用 `-` 隔開，輸出成**一個字串**。
最後一組不足 k 個字元就有幾個算幾個。k <= 0 時印 `invalid`。
只能使用 `len()`、切片、`+`、`*`。

```
s=abcdefgh, k=3  ->  abc-def-gh
s=abcdef,   k=2  ->  ab-cd-ef
s=abc,      k=5  ->  abc
s=abc,      k=0  ->  invalid
```
